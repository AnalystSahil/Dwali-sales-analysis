Diwali Sales Data Analysis
A Python-based Exploratory Data Analysis (EDA) project that analyses Diwali sales data to understand customer purchasing behaviour, demographic patterns, geographic activity, product preferences, and business opportunities.

Project Overview
Festive-season sales generate valuable customer and transaction data. This project uses Python, Pandas, and data visualization libraries to transform raw Diwali sales records into useful business insights.

The analysis focuses on:

Customer demographics
Gender-wise purchasing behaviour
Age-group analysis
State-wise activity
Occupation-wise analysis
Marital-status analysis
Product-category demand
Product-level purchasing activity
Customer segmentation
Business recommendations
Objectives
Clean and prepare the Diwali sales dataset.
Explore customer and transaction-level information.
Identify important customer segments.
Analyse purchasing behaviour by gender and age group.
Compare activity across states and occupations.
Identify popular product categories and products.
Create meaningful visualizations.
Generate practical insights for marketing and inventory planning.

Key Analysis Areas
Customer Analysis
Customer behaviour is analysed using gender, age group, occupation, marital status, and state. This helps identify the customer groups that show stronger purchasing activity.

Geographic Analysis
State-wise analysis helps identify regions with comparatively higher customer participation and supports regional marketing and delivery planning.

Product Analysis
Product and category analysis highlights popular products, stronger categories, demand patterns, and opportunities for product promotion and inventory planning.

How to Run the Project
1. Clone the repository
git clone <repository-url>
cd <project-folder>
2. Install the required libraries
pip install pandas numpy matplotlib seaborn jupyter
3. Open the notebook
jupyter notebook
Alternatively, upload the notebook to Google Colab.

4. Add the dataset
Keep the dataset in the path used by the notebook. If required, update the file path in the data-loading cell.

5. Run the notebook
Run all cells sequentially and review the generated tables, charts, and insights.
